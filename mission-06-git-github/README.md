## 6.1  Understanding the basic Git workflow:

|Git operation|My explanation|
| :--- | :--- |
|Check repository status (git status)|It shows what all files have been changed,staged and which files are waiting to be staged.|
|Stage selected changes (git add ) | it saves the edited files in a staging area where they wait to be committed.|
|Create a commit (git commit -m " ")| it saves the changes done in the project folder permanently in the history of the project folder with a short message.|
|View commit history (git log )|it shows the history of the commits (in order) that have been done in the project folder.|

## 6.4 Git operations explanations-
**Initialise a repository**-(git init):gives the opermission to the git to track the folder

**check status**-(git status):
checks which file are changed,and which files are tracked by git and which all are ready to be staged.

**Stage changes**-(git add ):
it prepares all the edited files to be included in the next commit.

**Commit changes**-(git commit -m " "):
Permanently saves the staged changes to the local history.

**view history**-(git log):
it shows the history of the commits(in order) in our local terminal.

**create or list branches**-(git branch):
it has two usecases,it list all the branches or it creates new branches.

**switch branches**-(git switch):
it switches the folder workspace between the branches in the terminal.

**publish changes**-(git push):it uploads all the local commits to the github (online).

**Retrieve remote changes**(git pull):
it downloads the updates from github to my local computer.
