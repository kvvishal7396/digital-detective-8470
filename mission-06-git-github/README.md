## 6.1  Understanding the basic Git workflow:

|Git operation|My explanation|
| :--- | :--- |
|Check repository status (git status)|It shows what all files have been changed,staged and which files are waiting to be staged.|
|Stage selected changes (git add ) | it saves the edited files in a staging area where they wait to be committed.|
|Create a commit (git commit -m " ")| it saves the changes done in the project folder permanently in the history of the project folder with a short message.|
|View commit history (git log )|it shows the history of the commits (in order) that have been done in the project folder.|
